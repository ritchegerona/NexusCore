# DEVELOPMENT_PROTOCOL

Rules

1. Architecture Before Code
2. Documentation First
3. Every subsystem requires a specification.
4. Every architecture change requires an ADR.
5. Offline-first is the default.
6. Gemma 4 E2B is the initial local provider.
7. CoreMind never depends directly on providers.
8. Intelligence Router selects providers.
9. Specialists execute work.
10. Repository is the single source of truth.
